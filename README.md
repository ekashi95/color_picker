Аналог "пипетки" в графических редакторах, позволяющий быстро получить код цвета в любой точке экрана. 

По клику левой кнопкой мыши в буфер обмена скопируется HEX-код цвета, а в окне приложения отобразится сам цвет и его HEX- и RGB-коды.

После захвата нужного цвета нажмите на кнопку "Пауза", чтобы при последующих кликах HEX-код в буфере обмена не менялся. Клики внутри окна приложения игнорируются.
